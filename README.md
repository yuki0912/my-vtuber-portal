# VTuber 綜合管理生態系 Portal (v3.0)

這是一個專門為了追蹤、管理喜愛的 VTuber 資訊以及重大推活活動（如新衣披露、生日回、連動大賽）所設計的前端輕量化管理系統。

## 📂 資料夾與檔案說明

- `index.html`：主頁面骨架，包含成員名冊與行事曆時間軸分頁。
- `assets/css/style.css`：客製化樣式調整（如美化捲軸與卡片動畫）。
- `assets/js/app.js`：核心邏輯處理器，掌管資料存取與畫面的即時渲染。
- `assets/images/avatars/`：建議將本機收集的 VTuber 立繪或大頭貼放在這裡。
- `assets/images/icons/`：存放網站相關的標誌或客製化小圖示。
- `assets/images/backups/`：手動點擊「導出全部」產生的 `.json` 備份檔可以集中放在這，以防瀏覽器快取被清空。

## 🚀 特色功能

1. **雙分頁流暢切換**：整合「成員名冊」與「活動行事曆」雙系統。
2. **無痛持久化儲存**：完全不需後端資料庫，資料直接綁定在瀏覽器的 `localStorage` 中。
3. **主推置頂功能（Favorite）**：一鍵按下卡片上的小星星，該 VTuber 的檔案將永遠置頂。
4. **一鍵全功能備份與還原**：提供 JSON 的導入/導出功能，跨裝置轉移資料超簡單。
5. **智慧型預設頭像**：新增成員時若無提供圖片網址，系統會依據名字透過 API 隨機派發可愛的動漫風格圖像。

## 🛠️ 開發與修改建議

- 如果想要更換預設的預設箱勢名稱，可以直接開啟 `index.html` 搜尋 `<select id="group">` 修改裡面的 `<option>` 標籤。
- 在網頁表單的「形象圖/立繪連結」輸入欄位中，可以直接填寫本機圖片的相對路徑，例如：`assets/images/avatars/aqua.png`。
